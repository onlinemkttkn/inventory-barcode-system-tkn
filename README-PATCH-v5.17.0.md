# TKN Final v5.17.0 — Mobile/PWA All Screens Patch

อัปโหลดทุกไฟล์ในแพตช์ตามโครงสร้างเดิมและวางทับไฟล์เดิม

## ติดตั้ง

1. สำรอง Source และ Supabase ก่อน
2. อัปโหลดไฟล์ทั้งหมดในแพตช์
3. Commit และ Deploy ผ่าน HTTPS
4. คอมพิวเตอร์กด Ctrl + Shift + R
5. โทรศัพท์ปิดแท็บเดิมแล้วเปิดใหม่
6. เมื่อต้องการติดตั้งเป็นแอป ให้กด “ติดตั้งเป็นแอป” หรือ “เพิ่มไปยังหน้าจอหลัก”

ไม่ต้องรัน SQL เพิ่ม

## หมายเหตุ

Service Worker จะไม่แคชคำสั่ง POST และไม่แคช Supabase API การขายและการปรับสต็อกยังต้องออนไลน์

# วิธีอัปเกรด TKN POS ERP v5.25.0

แพ็กนี้สร้างต่อจาก **v5.24.1 Box Workflow Cleanup** และเก็บไฟล์เก่าไว้เป็นทางถอย ไม่ลบไฟล์เดิมอัตโนมัติ

## ลำดับติดตั้ง

1. สำรองฐานข้อมูล Supabase และโฟลเดอร์เว็บปัจจุบัน
2. อัปโหลดไฟล์จากแพ็ก Patch ทับโฟลเดอร์เว็บไซต์ โดยคงโครงสร้างโฟลเดอร์เดิม
3. เปิด Supabase SQL Editor แล้วรันไฟล์:

   `sql/2026-08-05-unified-qr-sku-stock-v5.25.0.sql`

4. ตรวจว่า SQL แสดงผลสำเร็จและมี migration `TKN_V5_25_0`
5. เปิดเว็บไซต์แล้วกด Hard Refresh หรือเคลียร์ Site Data หนึ่งครั้ง เพื่อรับ Service Worker `v5.25.0`
6. ทดสอบตาม `UAT-v5.25.0.md` ก่อนล้างข้อมูลทดลองและนำข้อมูลจริงเข้า

## สิ่งที่ต้องรู้ก่อนใช้งานจริง

- แพ็กนี้ **ไม่ล้างข้อมูลสินค้าและสต๊อก**
- การล้างข้อมูลทดลองต้องทำหลังสำรองข้อมูล และควรทำด้วย SQL แยกที่ตรวจ foreign key แล้ว
- SKU ใหม่ถูกสร้างต่อหนึ่งล็อต ราคาทุนที่ฝังใน SKU จะไม่เปลี่ยนภายหลัง
- หากสินค้าเดิมเข้าล็อตใหม่ ให้สร้างสินค้าเป็นล็อตใหม่ ไม่แก้ SKU ของล็อตเดิม
- บาร์โค้ดผู้ผลิตเดิมเก็บเป็นข้อมูลค้นหา แต่ Barcode ที่พิมพ์ใช้ SKU ของร้าน
- หน้า POS ยังคงกติกา PIN ส่วนลดและการอนุมัติขายต่ำกว่าทุนเดิม

## ไฟล์สำคัญ

- `js/tkn-product-pattern-v5-25-0.js` กติกา SKU, QR, Barcode, ชื่อย่อ และคำนวณราคา
- `products-admin.html` สร้างสินค้า/ล็อตใหม่
- `print-labels.html` พิมพ์ QR และป้ายสินค้าแบบใหม่
- `stock-promotions.html` เลือกสินค้าจากสต๊อกและสร้างโปรโมชั่น
- `pos-v5-25-0.js` ดึงราคาโปรโมชั่นมาใช้ที่ POS
- `sort-pack-qr.html` ใช้ SKU ของล็อตในกระบวนการแยกสินค้าและปิดกล่อง
- `service-worker-v5.25.0.js` แคชไฟล์รุ่นใหม่

## การย้อนกลับ

ไฟล์ JavaScript เดิมยังอยู่ในโปรเจกต์ เพียงเปลี่ยน `<script src>` ใน HTML กลับเป็นเวอร์ชันก่อนหน้า และเปลี่ยน App Shell ให้ลงทะเบียน `service-worker-v5.20.6.js` จากนั้นเคลียร์ Site Data

ฐานข้อมูล v5.25.0 เพิ่มคอลัมน์และตารางแบบไม่ทำลายข้อมูลเดิม จึงไม่จำเป็นต้องลบคอลัมน์เมื่อย้อนหน้าเว็บ แต่โปรโมชั่นที่สร้างไว้จะไม่ถูก POS รุ่นเก่าเรียกใช้

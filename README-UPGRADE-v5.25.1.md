## รูปแบบมาตรฐาน

- Barcode: `SKUหลัก-ตัวอักษรAถึงZ+ราคาต้นทุน`
- Product QR: `TKN-P-` + Barcode เดียวกัน
- Box QR: `TKN-B-...`

ตัวอย่าง:

- Barcode / SKU: `F001-T150`
- Product QR: `TKN-P-F001-T150`

สินค้าทดลองเดิมที่ยังมีรหัส `F001` จะพิมพ์เป็น SKU ต้นทุนแฝงแบบคงที่ และทุกหน้าสแกนจะค้นย้อนกลับหา `F001` ได้ จึงไม่ทำให้สต็อกขาดการเชื่อมโยง

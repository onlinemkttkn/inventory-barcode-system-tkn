# TKN POS ERP v5.25.2 — ป้องกัน SKU ที่ไม่รู้จัก

## สิ่งที่แก้ไข
- หน้า Box QR จะไม่เพิ่มสินค้าที่ค้นไม่พบในหน้าจัดการสินค้า
- แสดง Pop-up พร้อมรหัสที่สแกน และมีปุ่มไปสร้างสินค้าใหม่
- หากฐานข้อมูลเชื่อมต่อผิดพลาด ระบบจะบล็อกรายการและไม่เปิดปุ่มสร้างสินค้า
- หน้าเพิ่มสินค้าใหม่รับรหัสจาก Box QR อัตโนมัติ และกลับมาหน้ารับสินค้าหลังบันทึกสำเร็จ
- ล้างเฉพาะรายการ placeholder เก่าที่ชื่อ “ยังไม่พบในหน้าจัดการสินค้า” ออกจากรอบงานในเครื่อง

## SQL
ไม่ต้องรัน SQL ใหม่ หากติดตั้งฐานข้อมูล v5.25.0 แล้ว

## ทดสอบ
1. สแกนรหัสที่ไม่มีในระบบ ต้องขึ้น Pop-up และห้ามเพิ่มเข้ารายการ
2. กด “ไปสร้างสินค้าใหม่” ต้องเปิดหน้าจัดการสินค้าและกรอกรหัสเดิมให้
3. บันทึกสินค้าแล้วต้องกลับหน้า Box QR พร้อมรหัสเดิม
4. กดยืนยันอีกครั้ง ต้องเพิ่มสินค้าได้ด้วย SKU จริง

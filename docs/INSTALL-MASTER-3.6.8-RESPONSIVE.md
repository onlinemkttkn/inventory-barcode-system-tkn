# Master 3.6.8 — Responsive Stable

ฐานระบบ: Master 3.5.9

## ขอบเขต

- ปรับ HTML ทั้ง 59 หน้าให้รองรับขนาดหน้าจอ
- เพิ่ม `css/responsive-no-scroll.css` เป็น Responsive Layer กลาง
- ยกเลิก Scroll ซ้อนในตาราง รายการ และคิวงาน
- ป้องกัน Scroll แนวนอนของหน้า
- ซ่อนภาพแถบ Scroll แต่ยังรองรับการเลื่อนด้วยเมาส์และการสัมผัส
- ปรับหน้าผู้ใช้และสิทธิ์เป็นการ์ดเมื่อพื้นที่จอไม่พอ
- เพิ่ม Viewport Meta ให้ครบทุกหน้า

## วิธีติดตั้ง

อัปโหลดไฟล์ทั้งหมดทับชุดเดิม แล้วกด `Ctrl + Shift + R`

ไม่ต้องรัน SQL และไม่มีการเปลี่ยนฐานข้อมูล

## จุดพักหน้าจอ

- จอใหญ่: ตารางเต็มพื้นที่โดยไม่สร้าง Scroll ภายใน
- จอขนาดกลาง: Layout ลดจำนวนคอลัมน์อัตโนมัติ
- แท็บเล็ต: เมนูเปลี่ยนเป็นแถบบนและฟอร์มเรียงใหม่
- มือถือ: การ์ดและปุ่มเต็มความกว้าง พร้อม Input ขนาดที่ไม่ทำให้หน้าจอซูม

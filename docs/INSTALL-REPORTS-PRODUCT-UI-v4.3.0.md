# TKN Reports Product UI v4.3.0

ปรับหน้า `reports.html` ให้ใช้ภาษาภาพเดียวกับหน้าจัดการสินค้าและ Dashboard

## ไฟล์ที่เปลี่ยน

- `reports.html`
- `css/reports-product-ui.css`

## รายการปรับปรุง

- Header แบบ Hero สีดำ–แดง พร้อมปุ่ม Dashboard สีเหลือง
- ตัวกรองรายงานขนาดใหญ่ขึ้น อ่านง่าย และจัดวางแบบ Responsive
- แก้ CSS ของฟิลด์ `hidden` ไม่ให้วันที่อ้างอิงกับช่วงวันที่แสดงพร้อมกัน
- การ์ดสรุป 11 รายการ พร้อมไอคอนและตัวเลขขนาดใหญ่
- ตารางรายการบิลหัวสีเข้ม ตัวหนังสือใหญ่ ปุ่มรายละเอียดเด่น
- หน้าจอมือถือแสดงรายการบิลเป็น Card เพื่อตรวจสอบง่าย
- ปรับหน้าต่างรายละเอียดบิลและรูปแบบตอนพิมพ์

## ขอบเขต

เป็นการแก้ UI/HTML/CSS เท่านั้น ไม่ได้เปลี่ยน Supabase, SQL, RPC, สิทธิ์ผู้ใช้, สูตรคำนวณ หรือ JavaScript รายงาน

## ติดตั้งแบบ Patch

คัดลอก `reports.html` และโฟลเดอร์ `css` จากชุด Patch ไปทับไฟล์เดิม แล้วกด `Ctrl + F5`

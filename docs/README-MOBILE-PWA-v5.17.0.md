# TKN POS / ERP Final v5.17.0 — Mobile/PWA Ready

รุ่นนี้เพิ่มชั้น Responsive และ PWA แบบกลางให้ทุกหน้า โดยไม่เปลี่ยนสูตรราคา ขั้นตอนขาย หรือโครงสร้างฐานข้อมูล

## ความสามารถหลัก

- รองรับโทรศัพท์ แท็บเล็ต โน้ตบุ๊ก และจอ Desktop
- เมนูล่างบนมือถือ: หน้าหลัก, POS, สแกน, สต็อก และเมนูทั้งหมด
- ตารางเลื่อนแนวนอนได้โดยไม่ทำให้หน้าเว็บล้น
- Pop-up และ Dialog ใช้พื้นที่หน้าจอมือถืออย่างเหมาะสม
- ปุ่มและช่องกรอกมีขนาดเหมาะสำหรับการแตะ
- รองรับ Safe Area ของ iPhone/iPad
- ติดตั้งเป็น PWA บน Home Screen ได้
- มี Offline Page และแจ้งสถานะเมื่ออินเทอร์เน็ตหลุด
- Service Worker แคชเฉพาะไฟล์หน้าจอ ไม่แคชคำสั่งบันทึกหรือ Supabase API

## ข้อจำกัด

PWA รุ่นนี้ยังเป็น Web App ภายใน Browser ไม่ใช่แอปปิดแบบ Native และไม่อนุญาตให้บันทึกการขายหรือปรับสต็อกขณะออฟไลน์ ข้อมูลสดต้องเชื่อมต่อ Supabase

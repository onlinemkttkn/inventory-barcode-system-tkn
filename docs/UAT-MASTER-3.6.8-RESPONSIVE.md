# UAT Master 3.6.8 — Responsive Stable

## ทุกหน้า

- [ ] ไม่มี Scroll แนวนอนของหน้า
- [ ] ไม่มีแถบ Scroll ซ้อนในตารางหรือรายการ
- [ ] เลื่อนเนื้อหาด้วยเมาส์และการสัมผัสได้
- [ ] ปุ่มและช่องกรอกไม่ล้นการ์ด

## Desktop

- [ ] Sidebar และเนื้อหาไม่ทับกัน
- [ ] ตารางใช้พื้นที่ตามขนาดจอ

## Tablet / Mobile

- [ ] เมนูเปิดและปิดได้
- [ ] ฟอร์มเรียงหนึ่งคอลัมน์เมื่อพื้นที่ไม่พอ
- [ ] Dialog อยู่ภายในหน้าจอ
- [ ] หน้าผู้ใช้และสิทธิ์แสดงเป็นการ์ด

## Regression

- [ ] Login และ Logout ทำงานเหมือนเดิม
- [ ] POS และ Cashier Shift ทำงานเหมือนเดิม
- [ ] บันทึกข้อมูลและสิทธิ์ทำงานเหมือนเดิม
- [ ] ใบเสร็จและหน้าพิมพ์ไม่เปลี่ยนขนาดจริง

# UAT — Mobile/PWA v5.17.0

ทดสอบอย่างน้อย 4 ขนาดหน้าจอ:

- โทรศัพท์ 360–430 px
- iPad/Tablet 768–1024 px
- Notebook 1280–1440 px
- Desktop 1600 px ขึ้นไป

## รายการสำคัญ

1. เข้าสู่ระบบและเปิดเมนูมือถือได้
2. เมนูล่างไม่บังปุ่มบันทึกหรือยอดรวม
3. POS เพิ่มสินค้า แก้จำนวน ส่วนลด และชำระเงินได้
4. Mobile Scan เปิดกล้องและย้อนกลับได้
5. Box QR ตรวจรับ จัดกล่อง ตรวจสอบ และล้างคิวพิมพ์ได้
6. Shopee/Lazada/นำเข้าสินค้าเอง กรอกฟอร์มและดูตารางได้
7. Reports เลือกช่วงวัน เปิด Pop-up และ Export ได้
8. ใบเสร็จและฉลากพิมพ์เหมือนเดิม ไม่มีเมนูมือถือในกระดาษ
9. เปิดแบบ PWA แล้วเข้าสู่ Dashboard ได้
10. ปิดอินเทอร์เน็ตแล้วระบบเตือน และไม่ยอมทำรายการข้อมูลสดแบบเงียบ ๆ
